## 📦 Build & Release Process

### Development Build
```bash
# Install dependencies
npm install

# Development mode with hot reload
npm run tauri dev
```

### Production Build
```bash
# Build for production
npm run tauri build

# Output: src-tauri/target/release/bundle/msi/
```

### Release Preparation
1. **Version Management**
   - Update `package.json` version
   - Update `src-tauri/Cargo.toml` version
   - Update `src-tauri/tauri.conf.json` version
   - Create Git tag: `git tag v1.0.0`

2. **Update Manifest**
   - CI (`release.yml`) signs the MSI, writes `latest.json` and uploads both; see `docs/UPDATER.md`

3. **Distribution**
   - Upload signed MSI to GitHub Releases
   - Update download links in documentation
   - Announce release to users

```

├── tauri.conf.json     # App configuration & plugins
├── Cargo.toml          # Rust dependencies  
└── capabilities/
    └── default.json    # Security permissions

updater/
└── latest.json         # Placeholder; release.yml overwrites it at build time

```

### Environment Variables
```bash
# Optional - for development only
VITE_OPENAI_API_KEY=your-api-key-here

# Production - use backend API instead
VITE_BACKEND_API_URL=https://your-api-server.com
```
